# Architecture decision records

This directory contains durable decisions that affect multiple milestones or establish a public project contract.

Use one file per decision. Do not use ADRs for ordinary implementation details or personal learning notes.

Recommended structure:

```markdown
# ADR-NNN: Decision title

- Status: proposed | accepted | superseded
- Date: YYYY-MM-DD
- Related milestones: M01, M02

## Context
## Decision
## Alternatives considered
## Consequences
```
